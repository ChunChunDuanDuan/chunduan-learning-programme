==================================================
1. Phase 1 的核心目標
==================================================

這次要解決的核心問題是：

目前所有功能都透過同一個 sidebar 導航，導致 Languages、Philosophy、Fitness、Record 等完全不同的工作 context 隨時可以互相切換。

我要把網站改成：

「彼此隔離的工作環境」

核心原則：

Navigation follows context, not capability.

也就是：

不要再把 Vocabulary / Sentences / Articles / Schedule 等功能全部放在全站 navigation。

而是先進入某個 context：

- Languages
- Philosophy
- Fitness
- Record

再顯示該 context 內的功能。

17. Ancient Greek Unicode / search normalization
==================================================

資料庫／storage 中必須保存原始正確 polytonic Greek。

例如：

ἄνθρωπος

不能把資料本身轉成：

ανθρωπος

但是搜尋需要建立 normalized search representation。

預設搜尋要能讓：

ανθρωπος

找到：

ἄνθρωπος

normalization 至少考慮：

- Unicode NFC/NFD differences
- acute
- grave
- circumflex
- smooth breathing
- rough breathing
- iota subscript

預設搜尋可以忽略這些 diacritics。

UI 顯示永遠使用原始正字法。

如果 architecture 合適，
可以保留 exact search 能力，
但不是 Phase 1 的必要 UI。

請把 normalization 寫成獨立 utility，
不要散落在 component 裡。

==================================================
54. 最重要的設計原則
==================================================

這次重構最重要的不是「做一個更漂亮的 dashboard」。

而是：

降低 context switching。

因此：

- fewer global links
- no global sidebar
- no global dashboard
- no global search
- environment isolation
- language isolation
- local navigation only
- shared data underneath
- deliberate cross-language workspace

不要因為「方便」而重新加入大量跨區 navigation。

Phase 1 的最終效果應該是：

我打開 German，
就感覺自己現在只在 German 網站裡。

我打開 Philosophy，
就感覺自己現在只在 Philosophy 網站裡。

但所有資料仍然存在同一套 Learning Programme 系統中。
