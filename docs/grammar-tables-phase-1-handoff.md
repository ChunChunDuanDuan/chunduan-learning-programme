# Learning Programme 2.0 — Grammar Tables Phase 1

1. **Routes.** `/languages/grc/grammar-tables` and `/languages/la/grammar-tables` are language-specific indexes. `/languages/{grc|la}/grammar-tables/[tableId]` opens a table. The existing language navigation and overview show Grammar Tables only for Ancient Greek and Latin. The other four languages and Cross-language remain unchanged.
2. **Shared components.** `src/components/grammar-tables/tables-index.tsx` provides search, categories, favorites and cards; `table-detail.tsx` provides a table page and related entries; `table-renderer.tsx` renders semantic tables with grouped headers, row headers, optional colspans, notes and local horizontal scrolling. `use-table-favorites.ts` handles favorites.
3. **Data model.** `GrammarTableDefinition` contains `id`, `language`, `category`, `title`, optional `subtitle`, `description`, `tags`, `sections`, optional `notes`, `relatedGrammarTopics` and `source`. Each section contains its table type, columns, explicit rows, optional notes and optional structured `vocabularyMatcher`. Static forms are reference data, not generated from Vocabulary.
4. **Ancient Greek tables.** Definite Article; First Declension (Reading Greek 1a–1d); Second Declension (2a–2b); Third Declension Overview (selected 3a, 3b, 3c, 3e, 3g); Adjective Paradigms; λύω; εἰμί; Prepositions + Cases. Forms use polytonic Greek.
5. **Latin tables.** Five noun declensions; Adjective Paradigms; First, Second, Third, Third-io and Fourth Conjugations; sum; Basic Irregular Verbs; Prepositions + Cases. Macrons are used where applicable.
6. **Favorites.** Stored in browser `localStorage` under a key scoped by authenticated user ID and language. The index has a Favorites filter and a pinned Favorites section. Favorites persist across reloads in the same browser, but are not synchronized across devices. No new storage backend was introduced.
7. **Grammar notes.** The detail page loads the current user's existing `language_notes` through `loadLanguage`, then links same-language Grammar entries whose ID/topic/tag matches a configured topic or whose title contains one. It does not copy or modify notes.
8. **Vocabulary examples.** The same user-scoped load supplies existing Vocabulary entries. Matching requires the same language, correct part of speech and an exact value in configured structured metadata such as Greek `declension_noun_class`/`declensionClass` or Latin `declension`/`conjugation`. It never infers a class from a word ending. Duplicate matches across sections appear once. If there is no match, the page shows an empty state.
9. **Migrations.** None for this phase. Existing Phase 1 migrations must be applied in the target Supabase environment for all related user-data features to work there; this phase does not apply them remotely.
10. **Responsive design.** Cards are one column on narrow screens, two from `sm`, and three from `xl`. Category buttons wrap. Each table has its own `overflow-x-auto` wrapper and a sticky first column, while the page and section containers use `min-w-0` to avoid whole-page horizontal overflow. Interactive targets use approximately 44 px minimum height. Browser-based iPad/iPhone visual inspection remains unverified because computer-use approval was blocked in this session.
11. **Lint.** `npm run lint` passes with zero errors and three pre-existing `<img>` warnings in blog pages outside this change.
12. **Typecheck.** `npm run typecheck` passes.
13. **Tests.** `npm test` passes 37/37, including new Grammar Tables coverage for scope, complete matrix widths, representative forms, search, structured relations and favorites.
14. **Production build.** `npm run build` passes.
15. **Adding future tables.** Add a definition in `src/lib/grammar-tables/grc/` or `src/lib/grammar-tables/la/`, register it in `src/lib/grammar-tables/registry.ts`, and add an appropriate vocabulary matcher only if existing structured metadata supports it. The renderer does not need changing for another ordinary paradigm or comparison table.
16. **Conservative content decisions.** The Greek third declension is explicitly an overview of selected Reading Greek classes rather than a claim to cover every subtype. Its variable vocatives are omitted. Latin irregular verbs are a principal-part overview, not full conjugations. Preposition glosses are core reading guides rather than exhaustive semantic rules.

Reference data was checked against the [Open University Reading Greek Language Reference Book](https://fass.open.ac.uk/sites/fass.open.ac.uk/files/files/classical-studies/Reading_Greek_Language_Reference_Book_May_2022.pdf), [Dickinson College Commentaries Latin grammar](https://dcc.dickinson.edu/grammar/latin), and the linked source on each table page.
